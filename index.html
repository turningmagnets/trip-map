How to use

Show on map: Poker only · Trails only · Both. ◆ Diamonds = poker rooms; ● Circles = trails.

Poker: diamond size/color = table count; filter by minimum tables. Default games = NLH available.

Trails: circle color = rating band (rose 4.0–4.3 · lime 4.4–4.7 · cyan 4.8+). Blue→black only.

Shared Esri World Dark Gray basemap (no OSM tiles). Open index.html via file://. Data: data/rooms.js, data/trails.js.
